# 管理后台

[← 返回 README](../README.md)

管理后台在 `https://你的域名/admin/`（本机开发时在 `admin/` 里运行 `npm ci` 和 `npm run dev`，端口 5175），只有管理员账户能登录。第一个管理员账户用 `.env` 里的 `FELLOWQUANT_ADMIN_EMAIL` 和 `FELLOWQUANT_ADMIN_PASSWORD` 创建（初始密码至少 12 位），见 [配置说明](CONFIGURATION.md)。

## 各个页面

- **概览**：注册人数、今天活跃、回测和 AI 用量、行情数据和备份；最近 30 天注册的新用户里有多少人跑出了第一个结果（事件研究、完成的回测或 AI 个股分析分析）、一小时内做到的人数和中位用时；最近 30 天每天各类 AI 的次数和文本模型的 token 用量。
- **用户**：每个人今天和累计的 AI 次数、回测数，可以改昵称、停用或恢复账户。停用后不能登录，已经登录的设备立即退出，数据不删除；昵称含违禁词的用户会标出来。管理员改的昵称不检查违禁词、不限次数，也不通知用户，改了会记进操作记录。
- **用户反馈**：用户在功能台提的建议（自动带上所在页面；同意被联系的才显示邮箱）、事件研究 / 策略回测 / AI 个股分析第一次出结果后“有用吗”的评价、注销时匿名的离开原因。上面是最近 30 天的汇总（没看过的建议、各功能“有用”的比例、离开原因的分布），下面的列表可以按种类和状态筛选，标成已读或已处理、写备注。概览里“新建议”卡片点了直接到这里。对有用的建议，可以在“积分与兑换码”里手动给这个用户发积分。
- **注册与邀请码**：选择开放 / 邀请码 / 暂停，生成和停用邀请码。邮件服务配好以后，注册要先填发到邮箱的验证码；邮件服务没配好时开放注册暂时注册不了（页面上会提醒），凭邀请码注册照常。
- **违禁词**：注册和用户自己改昵称时检查，昵称里包含就不能用。比较时不分大小写和全角半角，先去掉空格和符号；内置的“管理员、官方、客服、镜思、Prismind”删不掉，自己加的可以一次粘贴很多个，马上生效；管理员改的昵称不检查。
- **积分与兑换码**：用户手里还有效的积分、最近 30 天发出和用掉的积分；一次生成多个兑换码，设置积分、有效天数、几个账户能用和兑换期限；给某个用户加或扣积分，要写原因，用户在积分明细里能看到。
- **数据更新**：服务器磁盘空间和数据占用，剩余不到 5 GB 或 10% 时提醒；每日更新每一步的结果，可以只重新运行没完成的部分；财务数据的自动更新和手动更新；选数据集和日期下载历史数据；后台任务的进度和日志；手动备份。
- **系统设置**：AI 模型和密钥、各类 AI 每天的免费次数、积分规则、每日更新的开关和时间、BaoStock 请求间隔、邮件服务（注册验证码和找回密码）、知识库。
  - 保存后立刻生效，不用重启；没在后台设置的项照常用 `.env`。
  - 密钥和邮箱密码用 `APP_SECRET` 派生的密钥加密后存进数据库，页面上只显示前后几位，保存要再输一次管理员密码。换了 `APP_SECRET` 以后，后台保存的密钥会解不开，需要重新填写。
  - 可以先“测试连接”或发一封测试邮件（发到当前管理员账户的邮箱）；测试用的是页面上现在的值，不会保存。
- **操作记录**：改设置、改昵称、违禁词、停用用户、注册方式、邀请码、积分和兑换码、数据任务、备份，不记录密钥本身。

## 其他
