# 第二批：指数股票池、基准覆盖和研究记录

对应反馈 4、6、8、9。基于第一批 #99 合并提交。

- **股票池 → 指数股票池**：显示沪深 300、中证 800 的快照日期、来源和只数。确认后替换当前名单，保留过滤设置。中证 800 使用同一核对日的沪深 300 和中证 500 成分并集，任一来源缺少完整名单时不可选。新任务冻结名单和来源；回测起点早于名单快照时提示前视偏差。需要按当日成分变化回测时，回测页仍可选择已有的历史成分股范围。
- **策略回测 → 基准覆盖**：每日数据更新在常规刷新前检查沪深 300 的起点，缺历史时从本地个股行情起点补到已保存的首根基准日线（包含该日），继续检查价格质量。新回测的基准首尾都对齐才计算超额收益。历史回测能用已补齐的基准重新比较，原回测文件保持原样。
- **研究记录 → 列表和对比**：显示年化收益、股票池名称、快照日期、只数。历史指数范围使用区间内曾纳入的唯一股票数；旧记录仅从原始快照找回可验证的字段。
- **研究记录 → 查看审计**：列表显示主要警告，审计页列出评级规则、实际发现和复核建议。A/B/C/D 的底层评级规则沿用现有逻辑。

## 验收

1. 在股票池应用中证 800，核对名单和 800 只计数。提交回测后切换股票池，核对完成记录上的来源和只数。
2. 等每日更新补齐指数行情，或在「数据运维 → 更新当前股票池」只勾选「更新基准指数」，选沪深 300 并指定历史区间。以已知本地数据为例，可选择 2015-01-05 至 2022-01-04。更新后查看回测表单显示的实际覆盖，运行跨 2022 年初的回测核对超额收益。
3. 对比两条回测的年化收益和股票池，打开其中一条 C 级记录，核对每条警告和处理建议。

本地行情验证了两份名单分别为 300 和 800 只。历史基准的回填路径和收益对齐通过合成数据测试；当前执行环境不能连接行情供应商，实际下载需在可访问数据源的环境中验收。
